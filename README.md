Run PHP + MySQL GitHub Project Locally with Docker Compose

Step 1: Github Clone
git clone https://github.com/deepshikha-dubey/MyKrishna.git
cd MyKrishna

Step 2: Create docker-compose.yml file 
Step 3: Run this cmd : docker-compose up -d
Step 4: open Browser http://localhost:8082
